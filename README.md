# Vista-Saga-Plugin
Complemento independente para QGIS 4.x inspirado nos procedimentos do Vista SAGA/UFRJ com Avaliação Espacial, Monitoria, Assinatura, Combinação de Mapas, Conversão RS2/GeoTIFF/Vetor, Análises Voronoi e Sequenciador de Mapas GIF. Não contem código do programa original.

Independent QGIS 4.x geoprocessing plugin. Seven modules: spatial evaluation, spatial monitoring, spatial signatures, thematic map combination, RS2/GeoTIFF/vector conversion, Voronoi analyses (simple, mass, friction, mass and friction, including multiple weighted friction rasters), and map sequencing (raster, vector and mixed) to GIF.
