# Vista Saga Plugin — internationalization candidate (1.0.4-rc1)

Development branch only; **not released and not yet approved for publication**.
The previously published version 1.0.3 and its numerical algorithms are not replaced.

## Current scope

- Effective QGIS GUI locale via `QgsApplication.locale()` (not OS locale).
- Brazilian Portuguese is the source language.
- English is the fallback for languages without a completed catalog.
- Catalog `geosaga/i18n/en.json` provides translations for the main menu,
  home dashboard and core Processing titles/parameter labels.
- Internal provider, algorithm IDs, JSON keys, field names and computation remain unchanged.

## Limitations

Other dialogs, runtime warnings, interactive help, output reports and Processing help text
still contain Brazilian Portuguese. This is an initial integration, **not full multilingual
support**. Spanish, French, German and Italian translations are not supplied yet.
Do not describe these languages as translated.

## Validation

Run `python -m unittest discover -s geosaga/tests -p 'test_i18n.py'`
from the repository root. Testing in an actual QGIS 4.x/Qt6 instance is still required,
including locale override, restart, loading all seven modules and comparison of
algorithm output files with the approved 1.0.3 baseline.

## Translation workflow

Add exact source-phrase keys and translated phrases to `geosaga/i18n/<language>.json`.
Use the QGIS language (e.g., en_US -> en). Keep machine-readable IDs unchanged.
Any new dialog must wrap user-facing source strings with `tr()`.
Avoid changing or translating persisted output values or field schemas.
