# Roteiros dos vídeos (YouTube)

Um vídeo por módulo (7), em português do Brasil, inglês e espanhol, sobre os dados de Vila Serena
(`docs/tutorial/dados`). Cada roteiro: ficha, tabela de cenas (tempo, tela, narração, texto na tela) e material de
publicação (descrição, capítulos, tags). Os números da narração são os do tutorial (`numeros.json`).

- Texto: `roteiros_pt.py`, `roteiros_en.py`, `roteiros_es.py` (mesma estrutura).
- DOCX: `saida/`. Para gerar: `SOFFICE_PY=<soffice.py> python3 docs/videos/build_roteiros.py <trabalho> docs/videos/saida`.
