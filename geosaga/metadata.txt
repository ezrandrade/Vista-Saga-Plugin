name=Vista Saga Plugin
description=Geospatial assessment, monitoring, signatures, map combination, format conversion, Voronoi analyses and animated map sequences for QGIS 4.x.
about=Independent QGIS 4.x geoprocessing plugin. Seven modules: spatial evaluation, spatial monitoring, spatial signatures, thematic map combination, RS2/GeoTIFF/vector conversion, Voronoi analyses (simple, mass, friction, mass and friction, including multiple weighted friction rasters), and map sequencing (raster, vector and mixed) to GIF and PNG. The Voronoi friction model uses straight-line accumulation with an explicitly documented per-cell baseline. Numerical equivalence with the original Vista SAGA/UFRJ has not been established. Independently implemented; not affiliated with the original Vista SAGA/UFRJ project. The internal geosaga package and Processing algorithm identifiers remain unchanged for compatibility.
