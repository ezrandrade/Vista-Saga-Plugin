name=Vista Saga Plugin
description=Geospatial assessment, monitoring, signatures, map combination, format conversion, Voronoi analyses and animated map sequences for QGIS 4.x.
about=Independent QGIS 4.x geoprocessing plugin. Seven modules: spatial evaluation, spatial monitoring, spatial signatures, thematic map combination, RS2/GeoTIFF/vector conversion, Voronoi analyses (simple, mass, friction, mass and friction, including multiple weighted friction rasters), and map sequencing (raster, vector and mixed) to GIF and PNG. Voronoi analyses and spatial signatures follow the original Vista SAGA/UFRJ models and were validated against it (Voronoi: Simple and Mass 100 percent of cells, friction 99.4-99.7 percent; Signature: whole map 100 percent). Interface in English, Portuguese and Spanish, with tooltips on every control. Independently implemented; not affiliated with the original Vista SAGA/UFRJ project. The internal geosaga package and Processing algorithm identifiers remain unchanged for compatibility.

changelog=1.6.1 (changes since 1.0.4).
    Signature: redesigned on the original Vista SAGA model and validated against it. The first map in the list is the reference and its selection is the boundary; every map is signed, including the reference; union of the selection and optional per-feature results; Vista SAGA columns (total area, signed area, percent of signed area, percent of category). Raster tab (GDAL formats and RS2, same CRS and grid) and Vector tab (exact intersection, QGIS selection tools). TXT and CSV reports.
    Monitoring: results always loaded into QGIS (empty "Save to" = temporary); warning about features without a class; result tables copy to spreadsheets. Mann-Kendall removed for now (returns as a module in 2.0).
    Evaluation: vector tabs "Vector (Attributes)" and "Vector (Overlay)" with the Raster tab layout; reusable weights-and-scores project; classes without a score highlighted and blocking the run; new weights start blank.
    Voronoi analyses: now follows the original Vista SAGA, validated cell by cell (With mass = M/d²; friction uses the Vista SAGA cost). New polygon friction surface; direct vector output in all four modes; Raster and Vector tabs; GeoPackage, Shapefile, GeoJSON and FlatGeobuf outputs.
    Map combination: Raster and Vector tabs; results always loaded; slivers thinner than 1 cm tolerated and crossing residues merged into the neighbour; fields renamed to COD_nn/LEG_nn.
    Format converter: new Vector -> RS2 conversion; RS2 files with non-consecutive codes read and written correctly; CRS of RS2 remembered and confirmed; Vector -> GeoTIFF writes a palette and a .qml style with only the real classes.
    Map sequencer: Raster, Vector and Mixed tabs with the same height; "Move up/down" buttons; texts translated.
    All modules: tooltips on every control (English, Portuguese, Spanish); standard footer [Run] [Close]; temporary results named "Module - operation"; complete Spanish translation; new icons; GDAL exceptions scoped locally; code approved by the QGIS repository security scan.
    Full history: geosaga/CHANGELOG.md and docs/CHANGELOG_POR_MODULO.md in the repository.
