# Vista Saga Plugin 1.0.0 — Notas da versão

A versão 1.0.0 conclui a organização visual acordada para os sete módulos, sem modificar os cálculos.

Ordem apresentada no menu Raster → Vista Saga Plugin e no painel:

1. Assinatura
2. Monitoria
3. Avaliação
4. Análises Voronoi
5. Combinação de Mapas
6. Conversão de Formatos
7. Sequenciador de Mapas

A pasta Python `geosaga` e os algoritmos `geosaga:*` mantêm seus identificadores por compatibilidade. Os módulos foram homologados funcionalmente pelo usuário no QGIS 4.2.2 Windows; a validação Linux/Flatpak e a comparação matemática com o Vista SAGA/UFRJ original não estão concluídas. Não foi realizada submissão ao repositório oficial de plugins QGIS.
